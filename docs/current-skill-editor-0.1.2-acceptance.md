## 版本策略

准备、启动和桌面连接不再要求实际游戏的版本、build、SourceRevision 或 `steam.inf` 字节与制作基线相同。既有六文件租约也不会因为 Steam 更新而被判作未安装。界面常驻制作基线，客户端区域显示实际构建和修订；元数据缺失时显示未知，合格的客户端仍可尝试。

AppID 570、实际安装结构、原创资源清单与内容指纹、本机进程归属、认证控制通道、会话能力凭据和服务端房主/作弊环境继续核验。准备事务中途检测到更新时要求恢复或重试；这只保证该次准备的一致性，不要求后续使用固定的游戏构建。恢复不依赖原游戏版本，也不会移除外部修改的文件。

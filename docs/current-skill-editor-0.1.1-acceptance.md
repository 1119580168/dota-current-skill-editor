上述游廊两局预先准备了合法归属的房主真实英雄，用于验收编辑与面板。游廊自身的正常选人流程不在通过范围内；第二局及普通比赛的技能添加属于测试准备，不计为界面添加通过。两局游廊验证分别记录，不能合并为同一局的完整添加到删除流程。游廊与普通比赛验证的观测期间没有新增客户端崩溃转储。

## 验收范围与限制

0.1.1 的最终退出与六项安装文件恢复已通过。官方试玩本轮验证入口与面板切换，没有重测试玩内技能添加、删除或施法。跨面板真实施法、跨机多人、声音与所有技能的跨英雄效果未测试。上述单张游廊的握手结果不代表其他游廊均兼容。

游廊实机结果发生在最后一次桌面提示调整前。提示修正后的最终发行包已部署并核对字节，普通比赛的一键准备、冷启动、面板限制与桌面删除，以及官方试玩的面板切换和新提示均已验证；最终清理也已完成。

直接控制台载入试玩地图但没有英雄上下文时，工具按预期拒绝编辑。标准英雄详情页的试玩入口已通过；没有英雄的直接载图不列为故障。
